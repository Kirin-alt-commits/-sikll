# 实验与放疗读图

针对当前实验读取相关小节。仅解释研究图像与证据，不把实验处理参数改写为个人诊疗建议。

## 图像、条带与流式

- **显微 / IF / IHC：** 明确通道、marker、比例尺和取样区域；强度、阳性比例、阳性细胞数和定位是不同读数。比较亮度需要可比的采集与展示设置，先查图注/方法。代表性图像不能替代独立样本的定量结果；共定位不单独证明直接分子相互作用。
- **Western blot：** 对照泳道、目标蛋白大小、上样/归一化基准及定量。总蛋白变化与磷酸化比例变化不同。未提供完整条带或曝光信息时，可指出当前无法核查的部分，不凭裁剪图断言造假。
- **流式：** 核对坐标标记、变换、门控层级、父群、阳性阈值及对照。百分比需要分母；相同百分比不代表相同绝对细胞数。未给 gating strategy 时不猜门控步骤，也不凭颜色确认细胞身份。
- **活性 / 增殖 / 死亡读数：** 按测量原理解释代理指标。代谢活性、DNA 合成、克隆形成和凋亡标记回答不同问题，单个读数不包办全部结论。

## 肿瘤生长与机制

先明确模型、分组、处理时间、测量终点与样本单位。体积减小、生长延缓、肿瘤消退和生存获益分别陈述；不要用一个终点替代另一个。

纵向曲线中，同一动物的重复测量不是独立动物；留意退出、缺失和安乐死终点是否影响后期组均值。体重是耐受性线索之一，不能单独证明“无毒”。

机制图先读实际证据：表达关联、敲低/过表达、药物扰动、救援实验或直接作用检测。救援可支持某因素参与效应，仍需结合扰动特异性与对照，不自动证明唯一通路。只讨论当前材料能判断的替代解释。

## 放疗与克隆形成

- 核对剂量单位 Gy、单次或分次照射、给药时序、照射后观察时间与模型。只解释论文报告的方案，不补造参数。
- 克隆形成反映长期繁殖存活能力。核对接种细胞数、克隆判定、铺板效率（PE）和存活分数（SF）；克隆更少也可能受接种量、药物本身效应等影响。
- 常用定义为 `PE = 对照克隆数 / 对照接种细胞数`，`SF = 处理后克隆数 / (处理接种细胞数 × 对应对照 PE)`。计算时 PE 使用比例，例如 50% 写成 0.5。联合治疗的基准按原文核实，不默认都用同一个未处理对照。
- 在相同剂量、可比归一化下更低的 SF 可支持更强放射反应。若图只比较联合组与空白组，不能分离药物毒性与放疗效应；区分对照、药物、照射和联合条件所提供的证据。
- “联合效果更强”“放射增敏”“协同”不是同义词。增敏需有可解释的放射反应比较；协同需说明采用的相互作用模型及检验，不凭联合组最低就断定。
- SER/DEF 等指标需按文章给定终点和比值方向解释；没有原始曲线或模型时不自行计算。γH2AX 等信号变化可提示 DNA 损伤应答，但单时间点不能独立证明修复受阻或临床增敏。

克隆形成方法背景见 [Franken 等，Clonogenic assay of cells in vitro](https://www.nature.com/articles/nprot.2006.339)。具体归一化和联合处理设计仍以当前论文的方法为准。
