# 论文逐图解读 · 2.0

面向肿瘤、放疗与组学论文的阅读技能。逐个 panel 解释方法、坐标与分组、结果，以及结果能支持到哪一步；区分图中证据、作者解释和仍需验证的推断。

技能名保持为 `biomedical-figure-reader`，版本为 `2.0.0`。

## 怎么用

提供论文 PDF、清晰的图与图注，或可访问的论文链接，然后指定图号。材料不全时，技能先解释可确认部分，再指出影响判断的缺口；不会凭标题补出实验结果。

```text
$biomedical-figure-reader 解读 Fig. 2a，先讲一句话结论，再解释坐标和分组。
```

```text
继续讲下一个 panel，术语解释得简单一点。
```

```text
$biomedical-figure-reader 这张图真的能说明放射增敏吗？请把直接证据和作者推断分开。
```

```text
$biomedical-figure-reader 帮我读完整个 Fig. 3，最后串起各 panel 的证据链。
```

支持的重点图型包括生存曲线、森林图、热图、火山图、富集图、单细胞降维、空间与通讯分析，以及显微图、流式、蛋白检测、肿瘤生长和克隆形成实验。

## 安装与更新

本仓库根目录就是技能内容。将其放在目标环境的技能目录下，文件夹命名为 `biomedical-figure-reader`，保留 `SKILL.md`、`agents/` 和 `references/` 的相对位置。

例如，在 Codex 中可放到 `$CODEX_HOME/skills/biomedical-figure-reader`；未设置 `CODEX_HOME` 时使用用户目录下的 `.codex/skills/biomedical-figure-reader`。也可以通过所用客户端支持的技能安装入口导入仓库。

升级旧版时更新整个技能目录，不要只复制 `SKILL.md`：2.0 会按图型引用 `references/`。没有改动技能调用名，也没有增加必需的外部工具或 Python 依赖。

能否查看 PDF、放大图像或获取链接取决于运行环境提供的工具；技能本身不附带下载器、OCR 或统计软件。无法看图时会明确限定为文字解读。

## 2.0 改进

| 方面 | 初版 | 2.0 |
| --- | --- | --- |
| 资料核对 | 提醒信息不足时补图注 | 明确图像、图注、方法、正文各自的作用，处理版本与材料冲突 |
| 结论边界 | 提醒相关不等于因果 | 区分直接观察、作者解释、机制支持及临床外推 |
| 统计读图 | 通用注意事项 | 补充重复单位、误差线、非显著结果、HR 和亚组解释 |
| 专业图型 | 简要列举 | 增加组学、实验和放疗的按需参考 |
| 连续阅读 | 按 panel 阅读 | 明确“继续”、跨论文切换和整图请求的处理 |
| 技能入口 | 基础界面配置 | 提示词显式调用技能，增加版本标识与回归场景 |

## 目录与维护

```text
SKILL.md                              技能入口与共同规则
agents/openai.yaml                    展示名称与调用提示
references/statistics-and-survival.md  统计与生存分析
references/omics.md                    组学图型
references/assays-and-radiotherapy.md   实验与放疗
evals/scenarios.md                     维护者使用的行为回归场景
```

方法参考链接位于对应的参考文件中，只提供读图背景，不能替代正在阅读的论文。

修改后检查 YAML、相对链接和调用名，并按 [回归场景](evals/scenarios.md) 检查行为。场景是评测材料，不是已经通过模型实测的成绩单；结构校验也不能替代真实论文上的视觉理解评测。
